# 中间件版本决定：采用 RocketMQ 5.3.2

2026-10-17；T003、T004及后续T007/T037，关联REQ-006、018、020、021。

用户明确指令：“放弃4.9.8”。据此将4.9.8标为已放弃，不再拉取、验证或作为后续实施阻塞；继续采用已在T004真实往返通过的官方5.3.2，固定制品为：

`apache/rocketmq:5.3.2@sha256:4a80ff5cd4b0a3d3ef6dc338ce2028a85bd995648cb3aa5c3e753746d2dbc587`

Go SDK保持2.1.2。Compose已经使用该digest，本次仅更新状态与版本依据，没有修改运行代码或依赖。方案B、PostgreSQL权威、Redis与MQ、API/独立worker及显式迁移边界保持不变。

批准的需求/设计/审批/评审原文保持只读；其中4.9.8是历史输入，不覆盖本次用户决定。后续性能manifest使用5.3.2并注明与设计快照的软件版本差异，保持已批准的300在线/87请求每秒、数据关联、资源预算、场景与分组P95门槛；版本选择不再重复请求确认，实际测量仍待T037。既有T004证据不被解释为T007可靠业务消费、性能、安全或生产验收通过。

历史拉取失败保留用于追踪，不再列作风险或待办。T004后端部分已通过，整体仍等待两端验收；本决定不自动开始下一批业务任务、提交、推送或部署。
