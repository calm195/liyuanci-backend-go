## 首批实现范围与关键流程（历史记录）

1. `cmd/migrate` 为独立显式命令，仅接受 up/down 和外部 APP_DATABASE_DSN；总超时与退出信号支持取消，关闭自有连接池。日志使用注入 zap，命令层屏蔽驱动错误原文，不泄漏 DSN。Makefile 与 Dockerfile 构建迁移二进制，服务启动和启停入口不调用迁移。
2. `internal/migration` 内嵌 SQL，事务中获取 PostgreSQL 锁、校验版本/文件哈希后变更账号表并更新账本；未知版本和文件篡改拒绝。账号 UUID、生命周期/认证枚举、正代次/版本、非空昵称约束落库。回退只允许空表，有数据时事务回滚；不自动删除账号或初始化用户。数据库始终为权威，无 AutoMigrate。
3. `internal/securedata` 提供按次生成数据密钥的 AES-256-GCM 信封加密；KeyService 注入外部包裹/解包职责，Envelope 保存密文和 wrapped key，不存主密钥。结构化 AAD 绑定用途、对象与版本；失钥/取消/篡改失败关闭，无明文降级。临时数据密钥使用后清零，供应商切片所有权有明确契约。
4. 独立检索密钥 HMAC-SHA256 原语提供用途域隔离，无身份日志；不自行定义学号规范化或假定检索摘要轮换自动保证唯一。
5. 新增单元/真实 PostgreSQL 验证及 CI 迁移 job。实现范围只覆盖账号基础迁移和加密原语；REQ-003/005 的领域模型、约束及其余业务行为尚未实现，不能因本阶段关联 REQ 就认为需求已完成。详细操作见 [数据基础](../data-foundation.md)。

### 实现范围、流程与取舍

- 版本 1 文件保持不变，新增 `0002_identity`，迁移工具扩展为按连续版本前缀校验并原子追加全部待执行版本，down 在单事务逆序回退全部版本。身份表及轮换配置非空时拒绝回退，不删除占用或密文。每张表与全部字段含中文 COMMENT ON 数据库注释。
- `identity_secrets` 采用账号/用途两列主键的规范化行结构保存信封密文与内容版本，覆盖学号/OpenID；`identity_lookup_claims` 对用途/密钥引用/摘要唯一，且账号/用途/引用唯一；对普通账号/密文级联，模拟普通账号物理清理后释放占用，不提前在 deleting 阶段释放。姓名字段、审核与证据仍未接入。
- `internal/identity.Store` 注入数据库、Codec、DigestService 和 zap；身份串行事务锁先于账号锁，保证跨进程绑定/配置切换/回填不互相穿透。绑定锁账号并验证 lifecycle，计算数据库配置的全部活跃检索代，查重后同事务加密落库及双代写入。同值重放可成功；改号/重认留给后续审核命令。检索用途独立，不暗自裁剪或折叠学号。
- Configure 只初始化已可用引用，BeginRotation 最多双代，新绑定双写；Backfill 每批 1–100 条，先解密并复核旧摘要，再插入新摘要，失败整批回滚。FinishRotation 仅在所有密文有新代映射后移除旧代。状态在数据库，不由每个进程选择当前代；检索失钥拒绝降级，旧映射不会被失败批次清除。
- Reencrypt 每批 1–100 条，以用途/对象/原内容版本解密，再用活跃包裹密钥重新加密；目标引用与真实 Wrap 结果不一致时回滚。仅改信封，不改身份字节、内容版本或检索占用；这是合成密钥下的协议验证，不是供应商真实轮换/销毁验收。
- `bin/migrate permissions` 显式建立 migrator/API/worker/identity_maintenance 四个 NOLOGIN 组及当前表矩阵，迁移组拥有表，API 可绑定但不能改检索配置/读账本，worker 不能读身份密文，维护组可轮换和重加密。已存在不安全组属性/继承关系拒绝执行；不创建真实登录或口令，不对真实用户授组。public CREATE 撤销及所有权调整仅适用于专用业务库。生产账号的其他授权必须另行验证。
- 存储操作关闭 SQL 日志，完成日志仅操作/结果/耗时；不输出身份、摘要、密钥引用或供应商错误原文。账号/身份绑定不是认证审核通过，无新增 HTTP 路由，readyz 仍失败关闭。与 T006 的未来命令接线必须遵守身份锁先于账号锁，不可在已持有账号锁的事务中反序调用。
