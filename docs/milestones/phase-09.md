## 字段规则模块

internal/wish.Policy.ValidateContent 实现正式 0.2.0 WishInput 的分类、校区、报答方式、Unicode 码点和期限校验。正文保留原文，不做裁剪或 Unicode 规范化；拒绝无效 UTF-8、全空白及超过500码点，组合字符按独立码点计数。省略报答方式默认 sincere_thanks、省略有效期默认7天；显式空报答方式、0/负数/31天拒绝，接受1至30整数天。

可选标签保留“省略”和主动 undisclosed 的区别，校区与性别沿用批准枚举。年级通过注入 Grades 校验，不编造生产字典；未填不依赖字典，填写但字典缺失/异常/panic/取消均失败关闭。输出独立复制标签指针，失败不返回部分正文。中文完成日志仅含 operation/request_id/result/duration，拒绝非法请求标识，不记录正文/标签/供应商原始错误。

本模块只返回私有 Content，不注册 HTTP，不创建草稿、不持久化、不进行审核或公开。现有实体及迁移不变；同版本并发、账号guard下额度、幂等、加密持久化及公开查询属于后续接线，不能用纯规则测试代替真实事务证据。正式共享接口实施状态保持未实现，不修改共享需求/设计/审批及契约。

## 状态、额度与公开规则模块

Policy.Plan 使用调用方在账号 guard 下取得的完整当前快照、当前作者资格、活跃计数及数据库时间计算变更计划。先校验资格与聚合 expected_version，再校验动作；提交审核另校验 content_version，版本缺失400语义、过期409语义，内部继续使用 command 稳定错误类型。规则不接受直接指定目标状态；状态和内容版本溢出拒绝，不推进输入对象。

编辑支持草稿/驳回/待审/待上架/已上架/撤下/过期，拒绝应愿中/已实现/已还愿。生成新内容版本并回私有草稿，清除旧审核，保留原截止时间，保存下次上架刷新选择；只刷新期限也必须走新版本和重新提交，不能复用旧批准。已上架编辑另返回申请作废标记。提交审核仅草稿/驳回可做，清除旧审核并返回作废旧审核及新任务入队标记；与命令回执、加密内容、版本、申请及旧工作处理的根事务仍由后续 repository 接线执行。

上架只接受 ready 且当前版本批准：审核版本、限制代次和隐私代次必须精确匹配，学校检测完成且结果非空，涉校必须人工通过，已审公开正文合法。作者必须存续、认证通过、未受限，资源不得受限或持有隐私屏障。到期优先于额度判断：不刷新且截止时/之后得到 expired；额度大于等于3得到 ready，首次未成功上架不设置时钟，也不消耗刷新选择；有额度才设置 published_at，首次/显式刷新按本次数据库时间加整数天，普通重新上架保留原 expires_at。ready 不会因为额度释放自动上架，仍需显式再次执行命令。

CountActive 对已锁定同作者完整候选集计数，published 仅截止前占额，matching 无论原期限是否已过都占额，其余不占额；不能传分页结果或缓存计数。并发正确性仍要求事务内持账号 guard，不将纯计算当数据库并发证明。本模块没有实现匹配/实现/还愿回退，不声称 B01 或后续 T019/T023 交付。

Public 复用当前资格和审核条件，仅 published 且当前截止前可公开，其余返回不可见；只输出已审正文，不回退至原文。当前账号隐藏设置立即清空标签；涉校准确输出 UNVERIFIED_SCHOOL/未经证实。输出复制标签与快照中的指针，修改返回值不影响来源。规则的中文完成日志仅表示计算完成，不表示数据库提交、公开查询或队列已落地。
