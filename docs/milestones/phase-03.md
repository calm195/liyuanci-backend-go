## 已实现能力、实际行为与模块职责

- `internal/command` 提供显式注入 GORM/zap/config 的 Engine；统一拥有根事务、超时、错误映射、panic 回滚和提交后完成日志。拒绝接收已有事务，避免 savepoint 成功被误记成最终提交。该库未接入 HTTP 路由，API 保持健康端点及 readyz 503，无默认用户/管理员/令牌。
- 每次尝试先在真正只读事务解析数据库当前会话/主体，再通过服务回调发现完整参与者；按后台 guard、学生账号 UUID 排序持锁，重读参与集合，按心愿→申请→匹配→会话→审核任务→消息及 UUID 锁资源后再重读。集合变化整事务回滚并重新发现，不追加逆序锁。实际领域必须保证所有相关写入口遵守同一 guard 协议。
- 持锁后读取数据库时间，重新校验会话命名空间、主体、auth_epoch、撤销/到期、生命周期、学生认证/当前处罚或后台当前角色。warning 不限制交互，Ordinary/Verified 拒绝 mute/ban；Restricted 由服务端限定入口声明，不能由客户端选择。后台不隐含超管通吃。Authorize/Resolve 回调承担对象/参与者/隐私屏障等当前领域授权，不能以框架提供通用会话检查替代这些规则。
- 幂等范围为数据库主体、方法、规范路径和键摘要；请求摘要包含受控命令名、已验证类型化 DTO 与排序版本字段。有效同键同摘要返回技术引用，异摘要冲突；过期回执在主体 guard 内更新。重放重新授权和解析当前引用，不返回历史正文，跳过已由首次提交推进的原版本相等校验。业务与回执原子提交；外部发送不在回调执行。
- 服务端 RequiredExpectations 防止更新入口遗漏必填并发字段。expected_version 可绑定账号/心愿/申请/消息，wish_expected_version 仅心愿，expected_write_epoch 仅会话；不混用、不自动刷新期望值。匹配/审核表无通用 version，当前仅支持锁定；其他聚合和领域规则后续扩展。
- 40001/40P01/55P03、参与集合变化和版本冲突有配置上限与总超时，未知错误失败关闭；锁等待每次受 lock_timeout 限制。日志为中文结构化完成事件，含安全 request_id、duration、attempts、result/code/recovered，不包含令牌、键、正文、主体或驱动/panic 原文。
- `bootstrap_roles.sql` 增加回执三个更新列的最小授权，并清除历史列级 ACL；未改写已应用版本 SQL。后台身份表保持 API 无 UPDATE，通过迁移组拥有的固定 search_path、定参 SECURITY DEFINER 函数只锁行/返回授权状态，显式 revoke PUBLIC、仅后台组可 EXECUTE，含中文函数注释。已有表/字段注释全量回归通过；没有新增业务表字段。显式 permissions 安装函数，普通启动不授权；空库 down 后辅助函数随权限基础保留，表不存在时不能返回身份，重建应重放 permissions。
- `scripts/check-migrations.py` 为命令创建独立 commands 测试库，串行运行迁移/身份/命令真实测试；正式 Go 1.25 builder 中也离线运行库测试。原 CI migrations job 调用同一脚本，自动纳入新测试，远端未执行。README 更新库职责，设计接线说明见 [命令框架](../command-framework.md)。

## 设计取舍、未完成部分与完成边界

框架完成可独立推进的短事务/当前授权/锁序/幂等与版本基础，但 T006 整体不签验收。所有服务回调是可信代码，Tx.DB 不是沙箱；必须禁止独立事务/手动提交和网络副作用。Discover 必须列全参与者，权限/处罚/会话变更也须先取对应主体 guard。身份 Store 现有全局身份锁在账号锁之前，不可直接在已持账号锁回调调用；后续身份服务须统一 repository 和资源所有权。

Redis 未参与授权与锁，因此不能通过 Redis 状态放宽库内数据库检查；HTTP/网关的 Redis 故障限流与入口收敛未装配，未做真实 Redis 断连入口测试。真实会话签发/撤销服务及 HTTP 字段校验/错误隐藏待 T008，额度/B01、匹配、聊天、审核/处罚、隐私矩阵分别待领域任务，持久工作/发件箱/消费待 T007，独立删除意图与恢复待 T031/T035。不同数据库运行组仍受最小表权限限制，未实现审核/取消等入口不能借资源白名单自动获得 UPDATE 或退化为无锁读。技术完成日志不是业务审计和删除日志。T005 缺失交付和两端验收保持真实未完成状态。

## 后台消费复用锁序与最小账号 guard 权限

2026-10-21；T006/T007，REQ-014、016、018、020。消费方不能使用学生 Bearer 伪造命令主体，因此新增 NormalizePlan/LockPlan：只在调用方现有事务中规范化/锁定完整参与者，复用后台→账号→资源的既有顺序和数据库时间；不提交、不提供身份或决定领域授权，Actor 为空。最终事务日志归消费入口所有，辅助函数不声明提交成功。
