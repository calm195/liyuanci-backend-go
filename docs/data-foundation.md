# 数据迁移与加密基础

关联 T005，REQ-002、003、005、007、018、020。不依赖外部交付的业务表结构已补齐，T005 真实密钥集成未验收；真实恢复闭环另属后续删除/恢复任务；完整状态见 [第二阶段](milestones/phase-02.md)。

## 显式迁移与权限

`make build` 构建 `bin/migrate`，Docker 镜像同时携带 `/app/migrate`。SQL 内嵌在二进制中，不从当前工作目录读取；API、worker 和启停脚本不会调用它。现有 Compose 的 `migrate` 服务仍是隔离探针初始化，不能当作业务迁移使用。

通过受控运行环境注入外部 `APP_DATABASE_DSN` 后执行；禁止把下面工具连接到共享数据库或将生产凭据用于测试：

```sh
# 由专用数据库管理员首次初始化，然后显式分配权限。
bin/migrate up
bin/migrate permissions
# 仅在全部版本的表均可安全回退时执行，非空身份配置或账号均拒绝。
bin/migrate down
```

业务库命令接受一个 `up`、`down` 或 `permissions` 参数，总超时两分钟。另有 `journal-up/down/permissions`，只读取独立 `APP_RECOVERY_DATABASE_DSN`，不能混用业务库。信号取消及连接关闭有完成日志，命令不输出 DSN 或底层错误原文。不要向 API/worker 分发数据库管理员或迁移凭据。

版本 1 保留账号基础表；版本 2 保存 identity_lookup_keys（数据库轮换状态）、identity_secrets（按账号和用途的信封密文）、identity_lookup_claims（双代唯一占用）。版本 3 补齐身份审核/后台/姓名/对象/限制，版本 4 补齐心愿/申请/匹配/聊天/故事，版本 5 补齐审核/持久工作/清理及独立 evidence schema；版本 6 增加安全重驱动所需的发件箱替代标记及索引。完整表清单、权限和恢复库边界见[业务结构](business-schema.md)。表及每个字段均有中文数据库注释。身份采用规范化行结构，而非把姓名/学号/OpenID 全塞入单行：检索存储仍仅支持学号和 OpenID 用途，姓名及审核/对象模型已有结构、运行接线后续实现，不改变绑定不等于学生资格审核通过的语义。

迁移在单事务获取固定 PostgreSQL advisory lock、校验账本是已知版本的连续前缀及上下行 SHA-256，然后追加全部待执行版本；不改写历史文件或账本。down 在同一事务逆序回退全部已应用版本，不是只退一版；每版先锁表再检查空表，有数据或身份配置时拒绝，整批回滚。保留迁移账本。未知版本、缺口及篡改均拒绝；没有清空数据或强制回退开关。

permissions 是独立管理员动作，与迁移共用锁，不随启动或 up 自动执行。为专用库建立显式 NOLOGIN 权限组，不创建登录、密码或向真实账号授予成员资格：

| 组 | 当前职责 |
| --- | --- |
| liyuanci_migrator | 拥有本工具管理的表，可在 public 建表；独立迁移凭据显式使用此角色 |
| liyuanci_api | 账号 SELECT/INSERT/UPDATE，轮换配置 SELECT，密文与占用 SELECT/INSERT；无维护删除/重加密或轮换写权限 |
| liyuanci_worker | 保留原有探针角色，只读账号；新增 liyuanci_domain_worker 显式处理业务内容及任务，仍不能读取身份字段 |
| liyuanci_identity_maintenance | 只读账号，维护身份配置、密文与占用；不能读取迁移账本 |

新增后台审核/后台账号维护、普通隐私清理及证据只读/写入/删除组，权限详见上述完整矩阵；API 与普通后台组没有 evidence schema 访问权。

脚本转移已知业务表及证据 schema 所有权给迁移组，撤销 PUBLIC/运行组旧表权限后按矩阵重授，并撤销 PUBLIC 和运行组的 public 建表权。只适用于独立业务数据库；不应对共享应用库执行。已有保留组存在 LOGIN/超级用户/建库/建角色/复制/绕过行安全属性或继承其他组时拒绝，不擅自修正外部角色。真实登录身份和凭据绑定仍待外部交付，组授权不证明实际账号没有额外权限；生产须以最终登录身份重新验收。后续新增表需更新显式矩阵，不给未来所有表宽泛默认授权。

## 加密与唯一占用

`internal/securedata.Codec` 接受 KeyService 和 zap.Logger。每次加密生成独立 32 字节数据密钥和 12 字节 nonce，标准库 AES-256-GCM，结构化 AAD 绑定算法、用途、规范 UUID 对象标识及正内容版本。Envelope 保存算法、外部引用、wrapped key、nonce、认证密文；数据密钥不落库。临时数据密钥使用后清零，但 Go 内存管理下不承诺所有历史副本已擦除。

KeyService 由外部供应商实现；Wrap 不得修改/保留输入，Unwrap 交付独立切片供调用方清零。DigestService 由独立检索密钥服务提供用途隔离 HMAC-SHA256，不与数据包裹密钥复用。当前只有测试内的合成实现，没有生产适配器、默认密钥、文件密钥或服务启动接线。Envelope 与摘要均不是业务授权凭证，接入前须完成当前业务授权，日志不输出身份、摘要或供应商错误原文。

`internal/identity.Store` 用显式数据库事务进行身份占用，SQL 日志关闭。所有绑定、配置切换、回填与重加密共用一把数据库事务锁，再按需锁账号/身份行；配置行读无需额外 UPDATE 权限。该身份串行锁须先于账号锁取得，后续 T006/T011 必须遵守同一顺序，不能反序嵌入已持有账号锁的事务。此处不是完整领域命令框架。

Configure 显式初始化用途的可用检索密钥引用，不能直接替换现有配置。Bind 只接受正常存在账号、规范小写 UUID 和非空身份字节；权威学号规则、长度及规范化由接入方确认，本层不会隐式裁剪或折叠身份。计算数据库指定的全部活跃代摘要，先复核占用再加密写密文和所有代的占用。同账号同值幂等，不同账号冲突，同账号改值也拒绝；重新认证/改号流程留给审核命令。数据库主键对用途/引用/摘要唯一，账号/用途/引用亦唯一，不能靠无锁先查后写替代。

identity_secrets 对普通账号外键级联，claims 对密文字段级联；仅在普通账号完成物理删除时释放占用，不在 deleting 阶段提前释放。该关系不涉及证据域，也不代表 T031 完整注销协议已实现。

## 有界轮换与重加密

检索轮换与包裹密钥轮换独立，接口仅供内部受控维护调用，未提供 HTTP 路由或后台命令：

1. BeginRotation 校验新代可用，在数据库将 current 转 previous 并设置新 current，最多两代，禁止叠加第三代。
2. 新 Bind 同时检查/写入双代；旧数据仍由旧代占用保护。丢失任一活跃检索密钥时新绑定拒绝，不降级单代。
3. Backfill 按 UUID 排序每批 1–100 个缺少新代映射的密文字段，解密后验证旧代摘要一致，再计算并插入新代；批次失败全部回滚。可重试，不能跳过损坏数据后强制完成。
4. FinishRotation 同锁检查每个字段均有新代映射，才删除旧代占用并结束双代。返回失败时旧代保留；数据库仍为跨进程配置权威。
5. Reencrypt 按用途和目标包裹引用分批解密/重新加密，保持身份值、内容版本及检索占用不变。实际 Wrap 引用必须等于目标；失钥/引用不符时整批回滚，旧密文保留。每批 1–100 个字段，不把全部身份读入内存。

旧检索密钥不能在 FinishRotation 前停用；旧包裹密钥不能在重加密、历史备份和恢复条件确认前销毁。上述算法仅经合成密钥验证，没有供应商停用/销毁和生产轮换验收。新增 EncryptObject/DecryptObject 有界对象加密基础：调用方必须给出正字节上限，在受控内存中完成整个认证后才写明文，超限在密钥访问前拒绝，不使用明文临时文件；IO/失钥/取消/短写失败均有完成日志。它不定义学生卡上传门槛，不是不限大小的流式协议；底层 reader 的阻塞超时仍由调用方负责。图片安全及真实私有桶适配尚未实现。

## 验证

```sh
make fmt
make check
make build
python3 scripts/check-migrations.py
# 额外构建正式镜像，执行锁定工具链库测试、非 root 迁移 CLI 及失败日志脱敏检查。
python3 scripts/check-migrations.py --container
```

普通单元测试不依赖中间件；未显式提供专用 APP_MIGRATION_TEST_DSN 时 PostgreSQL 用例明确 SKIP。真实入口使用既有固定 digest PostgreSQL、随机容器/密码、三个独立逻辑库和 loopback 随机端口，串行执行业务结构/恢复库/迁移与身份 race 用例，避免回退用例与身份测试互相干扰。只停止/移除本次容器，保留卷，不使用 force/prune。测试会删除专用库测试表和合成账号并建立隔离 NOLOGIN 权限组，严禁提供已有开发/生产 DSN。CI 已有此入口，远端结果不能由本地 PASS 推断。
