# 数据库迁移

表结构只由 [版本 SQL](../internal/migration/sql) 定义；实体是读写映射，不执行 AutoMigrate。迁移、API、初始化与 worker 共用私有环境 YAML 的一组 database 字段。普通启动不执行 DDL。

初始化基线由九组 SQL 构成，已应用的版本保持原校验和。新库与已完成基线的数据库均使用以下入口显式应用待执行版本，应用启动期间不迁移。

```sh
bin/migrate -config configs/development.yaml up
bin/migrate -config configs/development.yaml permissions
bin/migrate -config configs/development.yaml opaque-blocks
```

账号由管理员预先创建，拥有专用业务库及其对象；禁止超级用户、BYPASSRLS、建库、建角色和复制权限。业务岗位、会话、资源归属及版本仍由领域函数复核。

## SQL 归属

| 版本 | 职责 |
| --- | --- |
| 0001_accounts | 账号、身份、学生卡、会话及屏蔽策略 |
| 0002_interactions | 心愿、应愿、匹配、聊天、故事与分享 |
| 0003_moderation | 审核、词库、安全治理、隐私和关怀 |
| 0004_execution | 持久任务、事件、通知及幂等回执 |
| 0005_whisper | 树洞、昵称、评论、抱抱和胶囊 |
| 0006_resources | 资料分类、资料、反馈和审计 |
| 0007_evidence | 证据隔离域 |
| 0008_functions | 会话检查、账号锁及受限内容投影函数 |
| 0009_relations | 跨表外键、循环引用与单向切换触发器 |
| 0010_wordlist_entry_status | 词条停用状态，存量条目默认启用 |
| 0011_trial_content | 心愿与悄悄话的版本标题、自定义报答、本人头像与自选标签，以及受限标题审核投影 |
| 0012_module_guide | 模块说明草稿、独立发布快照与本人确认版本 |
| 0013_account_avatars | 账号头像引用、私有 COS 对象摘要、上传预约与清理回执 |

基线按模块声明字段、主键、唯一约束、CHECK、索引和中文对象注释。跨表外键集中在基线第九组，避免模块建表顺序与循环引用耦合。未启用的屏蔽策略行、三类空词库基准行和未编辑的模块说明空草稿属于初始化数据，不创建业务账号或示例内容。

已有开发库显式执行 `up` 后保留现有业务数据。历史内容缺少标题时使用「未命名心愿」或「未命名悄悄话」，新标题和自定义报答随内容版本进入审核，公开读取使用已审投影。模块说明初始为空，由超管保存草稿并发布后供小程序读取。

技术账本定义单独位于 [metadata/ledger.sql](../internal/migration/metadata/ledger.sql)，用于在读取版本目录前初始化校验账本。迁移器从成对 SQL 文件生成连续目录，拒绝断号、重复、孤立回退和校验和不符。

## 事务和回退

`up` 在同一事务、同一迁移锁内完成版本 SQL、实体字段存在性检查及应用权限配置；权限失败时结构与账本一起回滚。无新版本时不推导字段或修复漂移；缺表、缺字段必须通过明确 SQL 修正。字段类型、默认值及数据库约束仍以版本 SQL 为准。

`permissions` 只重放当前应用账号策略和授权，不定义表或函数，不创建角色，不转交对象所有权；未完成版本初始化或存在未登记行策略时拒绝执行。

`down` 仅支持整体空库回退：迁移器先锁定全部已注册业务表，再检查真实数据，最后逆序执行各模块回退。未使用的初始化基准和未编辑的模块说明空草稿允许回退；任何业务记录、已更新词库基准或已启用的屏蔽策略均拒绝。检查不会因 FORCE RLS 隐藏数据而误判为空；失败恢复原设置，检查通过也恢复 FORCE 后再执行回退。并发写事务提交后必须重新检查。

`internal/testconfig/sql` 中的受限角色矩阵、数据库日志及 [probe.sql](../internal/testconfig/sql/probe.sql) 探针建表脚本只用于隔离测试，不嵌入运行制品。探针脚本由测试显式读取，用于对象注释和实体映射检查，不参与业务版本编号或迁移账本。当前删除恢复使用加密文件账本。完整运行方式见 [配置说明](../CONFIGURATION.md)。
